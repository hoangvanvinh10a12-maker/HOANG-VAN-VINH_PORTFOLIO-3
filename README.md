# HOANG-VAN-VINH_PORTFOLIO-3

A premium portfolio website built with HTML, CSS, and JavaScript featuring autumn-themed design, interactive elements, and Vietnamese content.

## Features

- **Autumn Theme**: Warm yellow/orange color palette with realistic falling leaves animation
- **Light/Dark Mode**: Toggle between themes with localStorage persistence
- **Interactive Gallery**: Click project images to view in modal with navigation
- **Responsive Design**: Optimized for all screen sizes
- **Smooth Animations**: Elegant hover effects and micro-interactions
